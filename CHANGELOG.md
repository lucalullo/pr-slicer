# Changelog

## 0.1.0

Initial Technical Preview.

- local `plan`, `verify`, `materialize`, `explain`, and `doctor` CLI commands;
- raw Git diff and hunk parsing with exact final-tree reconstruction;
- JavaScript/TypeScript AST and semantic analysis;
- dependency graph with serializable evidence;
- deterministic Union-Find, SCC, topological ordering, and bounded segmentation;
- terminal, Markdown, and versioned JSON reports;
- explicit local project checks with reduced environment, timeouts, and bounded logs;
- deterministic commit creation and atomic local branch updates;
- large-file, binary, rename, CRLF, Unicode, symlink, and gitlink handling;
- packaging tests, benchmark suite, and cross-platform CI configuration.
