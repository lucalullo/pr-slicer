# Security Policy

## Supported versions

The supported preview line is `0.1.x`.

## Reporting a vulnerability

Use GitHub Private Vulnerability Reporting from the repository's **Security** tab for sensitive reports.

Do not open a public issue containing:

- credentials or secrets;
- private source code;
- exploit payloads that expose private data;
- sensitive repository contents.

Include the PR Slicer version, Node.js version, Git version, operating system, and the smallest safe
reproduction you can provide.

The threat model, local-check execution model, Git hardening, and current limitations are documented in
[docs/security.md](docs/security.md).
